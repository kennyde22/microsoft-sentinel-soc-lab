**Microsoft Sentinel SOC Lab | Windows Authentication Triage**

Microsoft Sentinel SOC portfolio lab covering Azure Monitor Logs ingestion, KQL investigation, and Sentinel workbook monitoring. The lab reconciled 75 simulated Windows authentication events against the source dataset and identified eight failed logons followed by a success for the same account, source IP, and host. The project includes an investigation report, workbook screenshots, and Microsoft Defender rule simulation evidence. Scheduled alert and incident generation were outside the completed scope.
